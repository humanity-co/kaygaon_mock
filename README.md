# Kaygaon Paper Mills — Operations & MD Dashboard (Mock)

Clickable prototype of the proposed digitisation platform for Kaygaon Paper Mills Pvt Ltd. It works around DataMan ERP, which stays unchanged; the app only reads DataMan's Excel reports.

> **All operational and financial figures are sample data, not real Kaygaon numbers.** Company profile facts (kraft paper 14–28 BF, 36,000 MTPA installed capacity, production since 1992, Gangapur plant) are from public records.

## What's here
| Path | What it is |
|---|---|
| `index.html` | Clickable app demo: MD dashboard (Overview, Production & Quality, Cost, Raw material, Sales & Dispatch, Money, Compliance & People, Profit by grade, Forecast & Planning), MD Desk (Morning Briefing, Decision Inbox, Commitments, Ask Kaygaon with voice), Mill Map, Truck Yard, Gate Entry, QC, GRN & Bills, Truck Journey, Phone view, TV mode |
| `md-brief/index.html` | One-page plain-English brief for the MD: problem, truck flow, rollout, what we need |
| `docs/` | Digitisation blueprint v1 and v2 (with the MD intelligence roadmap) |

## Run it
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch `main`, root). Everything is static; data lives in memory and resets on reload.
